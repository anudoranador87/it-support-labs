# CCNA Labs — Cisco Packet Tracer

Hands-on labs for CCNA 200-301 preparation, built with Cisco Packet Tracer.

Each lab will contain my own topology, notes, configuration details, screenshots, verification steps, troubleshooting notes, and key takeaways. The aim is to understand the concepts rather than simply copy a configuration.

> I'm following Jeremy's CCNA course. Lab exercises will be independently rebuilt and documented in my own words.

## Tools

- Cisco Packet Tracer
- Cisco IOS CLI
- Anki — spaced repetition

## Documentation Approach

As I work through each lab, I will document:

- **Objective:** What the lab is intended to teach.
- **Topology:** Devices, links, and any relevant addressing.
- **Configuration:** Commands and settings applied.
- **Screenshots and evidence:** Captures from my own Packet Tracer work.
- **Verification:** Tests and command output used to check the result.
- **Troubleshooting:** Issues encountered, evidence collected, and fixes tested.
- **Key takeaways:** What I learned and what I need to review.

## Goal

Build practical networking skills for IT Support and Service Desk roles while developing a strong foundation for future cybersecurity studies.

The labs will be marked as completed only after I have built them, tested the expected behaviour, and documented my own results.
