## Checklist de calidad

- [ ] Capturas recortadas (sin barra de tareas completa ni ventanas irrelevantes)
- [ ] Sin nombre de usuario real de Windows visible
- [ ] Sin IPs/redes ajenas al laboratorio
- [ ] Contraseñas difuminadas o recortadas (si el repo es público)
- [ ] Formato consistente (PNG para capturas, MP4 para vídeos)
