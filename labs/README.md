# Labs

Practical IT Support case studies. Each lab keeps a permanent path, so its link remains stable while its status changes.

| Lab | Status | Area | What it demonstrates |
|---|---|---|---|
| [Linux Wi-Fi Driver Fix](linux-wifi-driver-fix/) | In progress | Linux troubleshooting | Identifying network hardware, inspecting kernel logs and modules, installing drivers and verifying connectivity. |
| [Windows Server UEFI/GPT and Active Directory](windows-server-uefi-gpt-ad-ds/) | Completed | Windows Server / Active Directory | Resolving a UEFI/GPT installation failure, deploying Windows Server, configuring AD DS and verifying the initial domain. |
| [Active Directory Multi-DC Environment](active-directory-multi-dc/) | In progress | Virtualisation / Active Directory | Hyper-V, Internal + NAT networking, `TAILWIND-DC1` promotion, AD DS and DNS for `tailwindtraders.internal`. |

## Status definitions

- **Completed** — executed, verified and documented with sufficient evidence to explain the result in an interview.
- **In progress** — documents work already performed; remaining work is explicitly identified and is not presented as completed evidence.

Historical and superseded material is retained separately in [archive](../archive/).
