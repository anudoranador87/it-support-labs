## How to read the case studies

Start with the completed [Windows Server and Active Directory setup](07-windows-server-uefi-gpt-ad-ds/) case study. It provides the clearest view of the investigation process, the technical environment, the evidence collected and the final verification.

The other folders represent work in progress or planned case studies. They are kept visible to show the direction of the portfolio, but the **Completed** status identifies the work currently ready for detailed review.

For the broader context, return to the [main portfolio README](../README.md).
