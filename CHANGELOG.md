# Changelog

All notable changes to this project are documented in this file.

## [1.2.0] - 2026-08-20

### Changed

- Replaced status-based lab folders with permanent numbered routes under `labs/`.
- Moved historical material from the active tree to `archive/legacy-labs/`.
- Added frontmatter metadata to active lab READMEs so status changes do not require moving folders.
- Added `labs/README.md` as a permanent-route index.
- Added `templates/lab-template.md` for consistent future documentation.
- Refocused Lab 08 on client domain join, DNS verification and user authentication, following the completed server and AD DS work in Lab 07.
- Updated root `README.md` and `LABS-ROADMAP.md` with stable paths and the new Active Directory progression.
- Corrected moved-document links and removed stale references to the former `CORE-LABS`, `legacy-labs` and top-level `Lab-*` layout.

## [1.1.0] - 2026-08-20

### Changed

- Separated labs into completed, in-progress, planned and legacy categories.
- Added the Windows Server UEFI/GPT and Active Directory lab with embedded visual evidence.
- Updated the repository index and roadmap to reflect the practical evidence.

## [1.0.0] - 2026-08-04

### Added

- Initial troubleshooting scenarios for SSH, Python system health, Windows Update, Active Directory and DNS.
- Initial study notes, documentation, tools and legacy practice material.
- `CHANGELOG.md` to track project evolution.
