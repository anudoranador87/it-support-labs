# 🏗️ Infrastructure Analysis & Optimization

Este módulo contiene análisis detallados de infraestructuras informáticas para diferentes tipos de organizaciones. El objetivo es identificar cuellos de botella, riesgos de seguridad e ineficiencias operativas, proponiendo soluciones escalables y profesionales.

## 📂 Casos de Estudio

| Escenario | Tipo de Organización | Enfoque Principal |
| :--- | :--- | :--- |
| [**Escenario 1**](scenario-1-network-funtime.md) | Software (Open Source) | Estandarización de hardware, inventario y automatización de despliegue. |
| [**Escenario 2**](scenario-2-wd-widgets.md) | Ventas (Rápido Crecimiento) | Escalabilidad, migración a la nube (M365) y automatización con PowerShell. |
| [**Escenario 3**](scenario-3-dewgood.md) | ONG (Presupuesto Limitado) | Resiliencia, seguridad de cuentas y profesionalización de backups. |

## 🛠️ Metodología Aplicada
En cada análisis se ha seguido un proceso sistemático:
1.  **Auditoría de Estado Actual:** Evaluación de hardware, software, red y procesos humanos.
2.  **Identificación de Riesgos:** Detección de puntos únicos de fallo, brechas de seguridad y falta de escalabilidad.
3.  **Propuesta Técnica:** Soluciones basadas en mejores prácticas de la industria (Regla 3-2-1, Active Directory, Automatización).
4.  **Análisis de Beneficio:** Justificación de cada mejora en términos de eficiencia, seguridad y coste.
