# Archive

Esta carpeta contiene material histórico de práctica que se conserva como referencia, pero no forma parte del recorrido activo del portfolio.

## Legacy labs

Los laboratorios anteriores se encuentran en [`legacy-labs/`](legacy-labs/). Su contenido puede ser útil para revisar experiencias iniciales de hardware, Linux y mantenimiento, pero no se mezcla con los 16 laboratorios permanentes del directorio [`labs/`](../labs/).

> El material archivado no se elimina ni se presenta automáticamente como experiencia completada. El estado y la fecha de cada práctica deben interpretarse según su propio README.
