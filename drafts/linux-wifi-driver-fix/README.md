# Draft: Linux Wi-Fi Driver Troubleshooting

> **Not started.** This folder is reserved for a future hands-on troubleshooting case. It does not contain a completed lab, evidence, command output or verified solution.

## Intended scope

This draft will be used only if a real Wi-Fi adapter issue is available to investigate in a personal laboratory environment. When that happens, the final case study will document the symptom, evidence, hypothesis, diagnosis, remediation and verification.

## Evidence required before moving to `labs/`

- Exact wireless-adapter identification from `lspci`, `lsusb` or an equivalent tool.
- Relevant system evidence from `dmesg`, NetworkManager, kernel logs or another appropriate source.
- A documented hypothesis based on the observed output.
- The actual driver or firmware action taken, if applicable.
- Evidence that the wireless interface appears and connects successfully.
- A network and name-resolution test after remediation.

## Publication rule

Do not add passwords, Wi-Fi passphrases, MAC addresses, personal network names, personal paths or unrelated desktop content to future evidence.
