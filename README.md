## 🔎 Troubleshooting Approach

```text
Identify the problem
        ↓
Gather evidence
        ↓
Form a hypothesis
        ↓
Test the hypothesis
        ↓
Apply the fix
        ↓
Verify the result
        ↓
Document the solution
```

The objective is to document **why the problem occurred, how it was isolated and how the solution was verified**.
